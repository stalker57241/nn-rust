# nn-rust

Полносвязная нейронная сеть на Rust с нуля. Без внешних ML-библиотек, только чистый Rust.

WIP: проект в активной разработке, API может меняться.

## Что это

Библиотека для создания и обучения полносвязных нейронных сетей произвольной конфигурации. Слои задаются вектором размеров, число слоёв и нейронов динамическое. Backpropagation, gradient descent, сигмоида и bias реализованы вручную.

Проект учебный, но с реальной задачей: классификация MNIST.

## Возможности

- Динамическая конфигурация сети: [784, 192, 96, 10] или любая другая
- Прямой проход (forward) и обратный (backprop) с нуля
- Онлайн-обучение (SGD по одному примеру)
- Bias на каждом слое
- Функции активации через трейт Act (сейчас SIGMOID)
- Экспоненциальный decay learning rate
- Загрузчик формата IDX (MNIST)

## Текущий результат

MNIST, конфигурация [784, 192, 96, 10], 350 эпох:

- Train loss: 0.0008
- Test loss: 0.016
- Test accuracy: 98.14%

## Структура

- src/ — библиотека (neuro.rs, main.rs)
- mnist/ — данные и загрузчик формата IDX
- Cargo.toml — зависимости (только rand)

## Запуск

Нужен Rust toolchain. Скачай MNIST в mnist/:

- train-images-idx3-ubyte
- train-labels-idx1-ubyte
- t10k-images-idx3-ubyte
- t10k-labels-idx1-ubyte

Сборка и запуск:

```bash
cargo run --release
```

Для скорости обязательно --release, иначе обучение в разы медленнее. В Cargo.toml включены lto и codegen-units = 1.

## Что внутри

- NeuralNetwork — веса, bias, конфигурация слоёв, learning rate
- NeuralNetworkInternal — активации и предактивации по слоям для backprop
- FeedForward, FeedForwardInternal, FeedForwardRaw — трейты интерфейса
- Act — обёртка над парой функций (активация, производная)
- Randomf32 — инициализатор весов из диапазона

## Планы

- Softmax + cross-entropy для классификации
- Разные функции активации на разные слои (ReLU, tanh)
- Батчи вместо онлайн-обучения
- L2-регуляризация, dropout
- Сохранение и загрузка весов
- Оптимизация: переиспользование буферов, flatten весов
